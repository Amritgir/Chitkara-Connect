# CHITKARA CONNECT

**CHITKARA CONNECT** is a student-focused campus companion website designed to make campus navigation and lost-and-found management easier for students at Chitkara University Punjab Campus.

The project combines a **Campus Navigator**, **Lost & Found Portal**, and **Student Authentication System** into one simple and responsive web application.

### 🚀 Key Features

* 🗺️ **Campus Navigator** – Interactive campus map using Leaflet.js to search and locate important blocks, departments, and facilities.
* 🔎 **Search & Filters** – Quickly search campus locations and filter them by categories such as Academic, Facilities, and Food.
* 📦 **Lost & Found Portal** – Students can report lost or found items with details such as item name, category, location, description, date, and contact information.
* 🔐 **Authentication System** – Includes student login, signup, logout, and access control for protected features.
* 👤 **Owner-Based Management** – Only the student who posted a lost/found item can remove their post.
* 💾 **Local Storage** – User and lost-and-found data are stored using browser LocalStorage for a functional front-end experience.
* 📱 **Responsive Design** – Designed to work across desktops, tablets, and mobile devices.
* 🌙 **Theme Support** – Includes theme switching and modern UI animations.
* 🎨 **Modern Interface** – Clean navigation, cards, icons, animations, search functionality, and responsive layouts.

### 🛠️ Technologies Used

**HTML5 • CSS3 • JavaScript • Leaflet.js • Font Awesome • LocalStorage**

### 🎯 Project Objective

The main objective of CHITKARA CONNECT is to solve common campus problems through a centralized digital platform. Instead of searching manually for campus facilities or relying on informal communication for lost items, students can use one website to navigate the campus and connect with others regarding lost and found belongings.

This project demonstrates practical implementation of **front-end web development, JavaScript DOM manipulation, authentication logic, LocalStorage, responsive UI design, interactive maps, search/filter functionality, and user-focused problem solving**.
